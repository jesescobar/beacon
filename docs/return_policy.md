# Política de devoluciones y productos faltantes

## Productos faltantes

Si recibís tu pedido y falta algún producto, comunicate con Atención al Cliente por WhatsApp al 0971 444 600 o por email a info@plub.com. El reembolso se procesa por el mismo medio de pago que usaste para la compra. Para pagos online o por POS, el plazo de acreditación depende de las políticas del emisor del medio de pago.

## Cambios y devoluciones

### Productos perecederos

Solo se aceptan cambios si el producto no cumple con condiciones de inocuidad o calidad. El plazo para realizar el reclamo es de **24 horas** desde la entrega. Es obligatorio presentar el producto con su envase y etiquetas originales.

### Productos no perecederos

El plazo para solicitar un cambio es de **120 horas (5 días)** desde la entrega. Es obligatorio presentar el producto con su envase y etiquetas originales.

## Costos

- Si el producto no cumple con calidad, cantidad o idoneidad: el cambio es **sin costo** para el cliente. Plub absorbe el costo.
- Si el cliente quiere cambiar por otras características (talle, color, u otras): el cliente abona la diferencia de precio más el costo logístico. No aplican promociones sobre ese costo adicional.
- Plub puede ofrecer cupones compensatorios previo acuerdo con el cliente.

## Cancelaciones

Si el pedido es cancelado —ya sea por Plub o por el cliente— Plub procesa la devolución por el mismo medio de pago utilizado.
